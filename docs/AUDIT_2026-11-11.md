# Rigger 3 Revised audit — 11 November 2026

The review found calculation errors and missing coverage in the previous implementation. The fixes use the supplied Rigger 3 Revised book, including visual checks of the printed tables and mathematical symbols.

| Area | Corrections |
| --- | --- |
| Engines and handling | Off-road suspension subtracts 15 Speed. Hydrofoil Signature increases by 1. Sidecar and flotation penalties survive engine customization. Drive-by-wire applies after the other design changes; Load bonuses account for permanent equipment and remain independent of carried cargo. |
| Paired ratings and Hull | Both operating Speed ratings retain their own limits. Secondary Speed customization is available. Applicable Hull-rated engine, remote-control, thermal and gyro options use the same scale as their prices and limits. |
| Drop tanks | The installed Signature penalty is 1. Jettison restores the appropriate Speed and Handling, including combined drive-by-wire effects and rounding. |
| Catalog | Nine omitted battery entries follow the printed Cars: All Others formula. The catalog contains 117 chassis, 379 engine combinations, 226 rule entries and 165 retrofit entries. Nonpositive formula results retain source notes. |
| Factory equipment | Included arms, seals, torpedo tubes, launch controls, amenities, decks and GridLink participate in the design without duplicate charges. Factory arm Strength is retained. An unspecified factory torpedo loading method remains unspecified. |
| Prices and tables | Corrected firearm conversion kit prices and heavy-kit Availability, Smartlink I Street Index, ECD rating-5 design cargo, and pop-up micro-turret retrofit cargo. Vehicle-dependent parts inherit the vehicle’s Street Index and Availability; explicit overrides retain precedence. |
| Weapons and payload | Fixed mounts hold one weapon. Turret Weapon Values do not impose an artificial limit on fixed hardpoints. Ordnance uses appropriate mounts and distinct storage slots. Aircraft mount limits apply to combined ordnance mass. Sidecar hardpoints and man-portable ring weapons follow their printed restrictions. |
| Mixed installations | Individual settings distinguish manufactured and retrofitted instances. Uniform manufacture-time recoil adjustment does not silently cover later mounts. Retrofit recoil charges each applicable installation. |
| Capacity | External cargo mount limits use the manufactured vehicle’s internal cargo rating, including upgrades and permanent fittings. Storage batches cannot overlap or exceed their allocated slots. Shared torpedo-loading equipment is charged once. |
| Legacy conversion | Convertible tops map to the current revised option. The obsolete aggregate engine budget and unsupported options stay out of active calculations. All 128 standard source names remain classified. |
| Installation and editor | Replaced generic installation placeholders with printed tools, base times and skill tests. Corrected division symbols in armor installation targets. Invalid grid entries and missing quote prerequisites produce validation messages; rejected edits retain the previous design. |

The automated rules audit includes every electronics rating, every supported turret variant, targeted pricing/dependency/combination regressions, and calculation plus JSON round trips for all 379 stock combinations. The desktop suite exercises native Windows forms, invalid numeric edits, quote recovery, file overwrite/reopen, conversion and HTML output.

The stock and quote sweeps test execution and consistency. They do not independently prove every numerical field or every possible combination of options. Printed table fixtures provide independent numerical checks for the rows they cover. Final GM rulings, actual carried-item specifications, unlisted Street Index overrides and secret engine reliability rolls remain part of preparing and approving a vehicle sheet.

The subsequent 0.2.16 packaging change enables installer creation and native installation tests on normal Windows workflow runs. The package includes the self-contained runtime, installation instructions, a test report and an installer checksum. Installation, shortcut creation, installed startup, repair and saved-file preservation are checked before upload. Each historical installer and every Windows release are not covered by these tests.

Run the rules audit with:

```sh
dotnet run --project tests/TheShop.Rules.Audit -c Release
```
